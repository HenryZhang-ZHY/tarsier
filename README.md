# tarsier

管理显示器和屏幕时间的 Windows 小工具，用 Rust + [GPUI](https://gpui.rs)（[gpui-kit](https://gpui-kit.com) 组件库）编写。灵感来自 Twinkle Tray 和 Fadetop。

## 功能

- **亮度 / 对比度**：通过 DDC/CI 直接调节外接显示器（VCP 0x10 / 0x12）。
- **一键切换输入源**：给每台显示器选两个输入（比如台式机接 DisplayPort 1、笔记本接 HDMI 1），按快捷键或点托盘菜单就在两者之间来回切换（VCP 0x60）。
- **休息提醒**：连续工作到设定时长后，像 Fadetop 一样在所有屏幕上慢慢淡入一层半透明遮罩。遮罩不抢焦点，鼠标点击会直接穿过去，所以手头的事可以先做完。倒计时只在你真的离开键盘鼠标时才走，晃鼠标不算休息。推迟或跳过请用托盘菜单，或主窗口的「休息」页。
- **忽略也会被记录**：如果一直顶着遮罩工作，到休息时长的 2 倍时遮罩会自动淡出，这次记为「忽略」，过一个推迟时长后再提醒。
- **无感记录**：自己离开电脑超过休息时长（吃饭、开会、锁屏、睡眠）会被自动记为一次休息，不用点任何按钮。
- **打分激励**：每段连续工作按“有没有超时”打分，每天的健康分是按时长加权的平均值。另外还有积分、称号和连续达标天数。
- **全屏 / 演示时不打扰**：检测到全屏游戏、视频或 PPT 演示时推迟提醒。
- **开机自动启动**：写入 `HKCU\...\Run`，开机后静默常驻托盘。
- 自绘标题栏，启动时跟随系统浅色 / 深色主题；单实例运行，重复启动会唤出已有窗口。

## 构建

需要 Rust（见 `mise.toml`）和 MSVC 工具链 / Windows SDK。

```bash
cargo build --release
```

产物为 `target/release/tarsier.exe`。release 版不会弹控制台窗口。`--background` 参数表示启动时只进托盘（开机自启用的就是它）。

## 默认快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+I` | 在 A / B 两个输入之间切换 |
| `Ctrl+Alt+PageUp` / `PageDown` | 所有显示器亮度 ±10% |

## 一台显示器、两台电脑

两台电脑上都装 tarsier，都选好同样的 A / B。大多数显示器即使当前没在显示某一路信号，也会响应那一路 DDC/CI 命令，所以在哪台电脑上按 `Ctrl+Alt+I` 都能切换。如果你的显示器在非活动输入上不响应，就只能在当前显示的那台电脑上切过去。

## 配置

设置页里的「打开配置文件夹」对应 `%APPDATA%\tarsier\`：

- `config.json`：设置。下面这些只能在这里改：
  - `hotkeys`：快捷键，格式如 `"ctrl+alt+I"`、`"ctrl+shift+F12"`，留空表示禁用，修改后重启生效。
  - `monitors.<id>.input_names`：给输入起名字，键是十进制 VCP 值，例如 `{"15": "台式机", "17": "笔记本"}`（15 = DP1、17 = HDMI1）。
  - `monitors.<id>.extra_inputs`：显示器没有上报的输入值，例如 USB-C 常见的 `27`（0x1B）。
  - `brightness_step`：快捷键调节亮度的步长（百分比）。
- `stats.json`：每天的工作段记录。
- `tarsier.log`：日志。

## 评分规则

- 一段工作的时长不超过目标的 110% 就是 100 分；到 150% 降到 50 分，到 190% 降到 0 分。
- 每日健康分是当天各段分数按工作时长的加权平均。当天使用不满 15 分钟不评分。
- 每次休息按这段工作的分数得 10 / 6 / 2 分积分。跳过、推迟和忽略都不会直接扣分，但会让这段工作变长，分数自然就低了。连续达标（≥ 80 分）的天数会累加，没用电脑的日子不会打断连续记录。

## 已知限制

- 只支持外接显示器的 DDC/CI。笔记本内置屏和部分 USB 扩展坞后面的显示器无法调节。
- 不少显示器需要先在 OSD 菜单里打开 DDC/CI。
